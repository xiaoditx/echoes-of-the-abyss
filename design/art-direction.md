# 美术风格基线（Art Direction Baseline）

> 用途：阶段 1 素材搜集的筛选标尺；阶段 4 素材选用的最终依据。

## 1. 画面规格

| 项目 | 取值 | 说明 |
|---|---|---|
| 逻辑分辨率 | 1280×720（16:9 横屏） | 窗口可拉伸，内部按等比缩放 + 黑边（letterbox） |
| 美术形式 | 像素画（Pixel Art） | 拒绝高清手绘 / 矢量素材混用 |
| 基础瓦片尺寸 | 16×16 或 18×18 源像素 | 以素材包为准，选定后统一 |
| 屏幕放大倍率 | 整数倍（×3） | 1280×720 下 16px 瓦片 → 48px 屏幕像素 |
| 采样方式 | 最近邻（Nearest Neighbor） | Direct2D `D2D1_INTERPOLATION_MODE_NEAREST_NEIGHBOR` |
| 帧率 | 逻辑 60 fps；精灵动画 8~12 fps 逐帧 | 动画帧时长由配表控制 |
| 视角 | 侧视横版（Side-scrolling Platformer） | 对标《死亡细胞》的横版动作视角 |

## 2. 色调

- 整体：**暗色地牢 / 哥特幻想**。背景以深蓝、暗紫、墨绿、灰黑为主。
- 点缀色：高饱和的金（奖励/商店）、红（危险/伤害）、青绿（毒/魔法）、暖白（UI 文字）。
- 目标参考：Dead Cells 的「囚徒牢房」区域色调 —— 暗背景 + 暖色火把点缀。

## 3. 素材筛选规则

1. 必须是像素画风格，且瓦片网格能与 16/18px 网格对齐。
2. 成套优先：同一素材包内含角色 + 敌人 + 瓦片 + 装饰者优先。
3. 许可证：CC0 优先；CC-BY 可接受（记录署名义务）；CC-BY-SA / GPL 素材原则上不选用（与 WTFPL 分发存在传染性争议，选用前须填工单）。
4. 单个素材包体积 ≤ 200MB；素材库总量 ≤ 1GB。
5. 音乐：可循环的暗色氛围曲目（地牢探索、战斗紧张、BOSS 战各至少 1 首候选）。
6. 音效：打击、挥空、受击、跳跃、翻滚、拾取、开门、UI 确认/取消、死亡。

## 4. 技术约束（来自需求）

- 图片最终须为 WIC 可读格式：PNG 优先（带透明通道）。
- 音频最终须为 yumo audio 可播格式：WAV（PCM、≤2 声道）或 MP3。
- 堆库阶段**不做**格式转换，只下载与登记 manifest。
