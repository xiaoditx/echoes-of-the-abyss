# UI 流程设计

## 状态机

```
Boot（初始化/加载）
 → Title 主菜单
    ├→ Forge 熔炉（meta 升级）
    ├→ Run 开局 ─┬→ Pause 暂停（Esc，可回主菜单=放弃本局）
    │            ├→ Death 死亡结算 → Title
    │            └→ Victory 胜利结算 → Title
    └→ Quit 退出
```

## 画面规格

- 逻辑分辨率 1280×720，letterbox 适配。
- 字体：DirectWrite，UI 用系统无衬线（"Microsoft YaHei" 回退 Segoe UI），标题加粗。
- 风格：暗色半透明面板（黑底 α0.75）+ 暖白文字 + 金色强调；像素图描边按钮。
- 所有菜单键盘操作：↑↓ 选择，Enter/J 确认，Esc 返回；按钮同步响应鼠标悬停/点击。

## 界面清单

| 界面 | 内容 |
|---|---|
| Title | 大标题《深渊回响》；按钮：进入深渊 / 回声熔炉 / 离开；底部显示魂晶存量与版本号 |
| Forge | 升级项列表（图标+名称+当前等级+下级花费），↑↓ 选择 Enter 购买，魂晶不足红字提示 |
| HUD（局内） | 左上：血条（数字）+ 药剂数；右上：金币、魂晶、当前层名；底部中央：Boss 血条（仅 Boss 房） |
| Pause | 半透明遮罩；继续 / 放弃本局（回主菜单，金币按规则结算） |
| Death | 「深渊收回了你的回声…」+ 统计（层数/击杀/时长/金币→魂晶转化）+ 入账动画计数；Enter 回主菜单 |
| Victory | 「看守者倒下，深渊沉默。」+ 完整统计 + 通关用时；Enter 回主菜单 |

## 局内提示

- 拾取物：浮动文字（+1 金币 / 获得武器名）。
- 层切换：黑场淡入层名大字 1.5s。
- Boss 登场：标题条「看守者·巨岩魔像」+ 门关闭音效。

## 多语言（可选扩展）

文案全部集中在 `data/strings_zh.csv`（key,文本）。若时间允许加 `strings_en.csv` 并在标题界面提供切换；
默认仅中文，不阻塞核心循环。实现方式：`Text::get(key)` 查表，表在启动时加载。
