# 核心循环设计

## 单局循环（Run）

```
主菜单 → [可选：熔炉升级] → 开局
  → 第1层 囚牢平台（5~7房间）
  → 第2层 渗水深渠（5~7房间）
  → 第3层 深渊之心（4~5房间 + Boss房）
  → 胜利结算  ┐
死亡 → 死亡结算 ┘→ 主菜单
```

- 目标时长：通关 10~15 分钟（数值按此标定）。
- 每层末端一个**传送门**，进入后切换层并重生成关卡。
- 死亡/胜利都进入结算界面，把本局资源结算为永久货币后返回主菜单。

## 双货币

| 货币 | 获得 | 消耗 | 局间保留 |
|---|---|---|---|
| 金币（Coin） | 击杀掉落、房间拾取 | 局内拾取的药剂/武器即买即用（无商店 UI） | 否，死亡结算 5:1 转魂晶 |
| 魂晶（Soul） | 击杀少量掉落、金币转化、Boss 大额奖励 | 熔炉永久升级 | 是（存档） |

## 死亡结算

```
击杀数 / 到达层数 / 存活时间
金币 N × 0.2 → 魂晶
+ 击杀携带魂晶  → 合计魂晶入账 → 写存档
```

## 节奏标定（数值锚点）

- 玩家 DPS ≈ 45（三连击全中），Boss HP 600 → Boss 战约 60~90 秒。
- 每层清版时间 2.5~4 分钟（含探索与死亡重打）。
- 一个熟练玩家第三局左右可通关；新手 5~8 局。

## 操作（键鼠）

| 输入 | 动作 |
|---|---|
| A / D 或 ← / → | 移动 |
| Space / W / ↑ | 跳跃（支持土狼时间 0.1s、跳跃缓冲 0.12s） |
| J / 鼠标左键 | 攻击（三连击连段，移动中可攻击） |
| K / Shift / 鼠标右键 | 翻滚（无敌帧，短 CD） |
| L / E | 使用治疗药剂 |
| Esc | 暂停 |

## 局内强化（轻量）

房间内可拾取：药剂补给、心上限残片、**替换武器**（见 combat.md 武器表）。
不做局内三选一升级界面（保持切片聚焦；武器差异承担 Build 多样性）。
